# GOR Futsal Arena - Booking System

Sistem booking lapangan futsal online dengan fitur:

- ✅ Registrasi & Login User
- ✅ Booking Lapangan Real-time
- ✅ Pembayaran QRIS & Transfer Bank
- ✅ Dashboard Analytics untuk Admin
- ✅ Riwayat Transaksi

## Deployment ke Render

1. Fork repository ini ke GitHub
2. Buka [Render.com](https://render.com)
3. Klik "New +" → "Blueprint"
4. Pilih repository GitHub
5. Render akan otomatis deploy

## Local Development

```bash
# Install dependencies
cd backend && npm install

# Run server
npm run dev
